# Nexus-Base 硬件性能评估与容量预估

作为服务于本地 Agent 的张量检索引擎，`Nexus-Base` 在设计上需要极力压榨单机的硬件性能，同时保证不与宿主机的其他任务（如本地 LLM 推理或 IDE）争抢过多的资源。本篇对张量引擎在内存、磁盘 IO 及 CPU 算力方面的理论性能进行预估。

## 1. 内存消耗预估 (RAM & Mmap)

知识库的核心数据结构为 **HNSW（分层可导航小世界图）**。由于我们使用 `mmap` 进行内存映射，实际的物理内存占用取决于操作系统的页面调度（Page Cache），以下为理论容量评估：

### 预估基准参数：
* **向量维度 (D)**：假设采用标准的本地文本嵌入模型（如 768 维，`float32`）。
* **单节点向量大小**：768 * 4 bytes ≈ 3.07 KB。
* **HNSW 连边开销 (Overhead)**：每层最大连接数 `M=16`，双向边与元数据指针开销约 150-200 Bytes。
* **单条记忆 (Memory Fragment) 综合大小**：约 **3.2 KB**。

### 规模测算：
| 数据规模 (代码/文档片段数) | 理论内存映射大小 (Mmap Size) | 活跃热数据常驻内存 (Active RAM, 预估) |
| :--- | :--- | :--- |
| **10 万** (中型项目) | ~320 MB | ~100 MB |
| **100 万** (十年个人开发积累) | ~3.1 GB | ~1.5 GB |
| **1000 万** (大型企业代码库级) | ~31 GB | ~8-12 GB |

> **结论**：对于个人 Agent 终端，100万条经验记忆映射只需约 3GB 的虚拟内存，对现代 16GB+ 的开发机毫无压力。由于 `mmap` 的特性，冷数据会被 OS 自动换出，实际物理 RAM 占用极小。

## 2. 磁盘 I/O 性能评估

`Nexus-Base` 的磁盘负载主要发生在**冷启动加载**与**事务持久化 (WAL)**。

* **冷加载速度 (Cold Start via Mmap)**：
  * 使用 PCIe 4.0 NVMe SSD (读取约 5-7 GB/s)。
  * 针对 100万规模 (3GB) 的 `.nxpack` 快照，OS 建立内存映射仅需 **<50毫秒**。哪怕触发全量 Page Fault，全部扫入物理内存也只需 **<1秒**。
* **写入延迟 (WAL Sequential Write)**：
  * Agent 吸收新经验时，调用 `IngestExperience`。数据首先序列化并追加 (Append) 到 WAL (预写日志) 文件。
  * 顺序写入 NVMe SSD 延迟约为 **10-50微秒**。因此，对于 Agent 来说，写入是真正的“瞬间完成”。

## 3. CPU 算力与查询延迟评估

HNSW 的检索性能极为强悍。CPU 算力主要消耗在**余弦相似度计算**上。

* **指令集加速 (SIMD)**：
  * 在支持 **AVX2** 的 x86_64 CPU 上，单指令可同时计算 8 个 `float32`。
  * 对于 768 维张量，一次点积计算理论上只需不到 100 个 CPU 周期。
* **查询复杂度**：
  * HNSW 在百万级别规模下，查询路由访问的节点数一般在 100 - 300 个左右。
  * 单次查询的总余弦计算次数约为 300 次。
* **延迟预估 (Latency)**：
  * 在现代 3.0GHz 处理器上，计算 300 次 768维 的余弦距离耗时在 **亚毫秒级 ( < 0.2ms )**。
  * 包含 gRPC 网络序列化/反序列化及 Rust 线程上下文切换，单次 `RetrieveContext` 请求的端到端延迟可以稳定控制在 **< 2ms** 甚至 **< 1ms**。

## 4. 推荐硬件配置基线

针对 `Nexus-Base` 作为 Agent 知识挂载盘的使用场景，我们得出以下系统级硬件要求：

| 硬件维度 | 最低要求 (Minimum) | 推荐配置 (Recommended for Agents) | 备注 |
| :--- | :--- | :--- | :--- |
| **CPU** | 4 核心 / 仅标量指令集 | 8 核心以上，支持 **AVX2** 或 **ARM NEON** | 决定查询 QPS 及并发容忍度 |
| **RAM** | 8 GB | 16 GB 或 32 GB | 以支撑本地运行的其他大模型(LLM)和多任务 |
| **磁盘** | SATA SSD | **NVMe SSD** (PCIe Gen3 / Gen4) | HDD 绝对不可用，会导致极高的 Page Fault 阻塞 |
| **网络** | Localhost (无要求) | Localhost (无要求) | IPC 走 Unix Domain Socket 或 127.0.0.1 |
